# 🧠 2 Boxen in Dart

## 🟦 1. Variable-Verhalten (Modifier)

```text
var / final / late / dynamic
```

👉 regelt **wie die Variable sich verhält**

* änderbar?
* wann gesetzt?
* typ-flexibel?

---

## 🟨 2. Typ (Datenform)

```text
int / String / List<T> / Map / Class
```

👉 sagt **was die Daten sind**

---

# 📌 Mini-Merksatz

```text
Modifier = Verhalten der Variable
Type = Was die Daten sind
```

var = automatischer, fester Typ (kein dynamischer Typ)

dynamic a = 5;
