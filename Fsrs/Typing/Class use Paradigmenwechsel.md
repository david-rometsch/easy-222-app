Du hast im Moment eher diese Idee im Kopf:

```
Klassen = OOP = Overengineering
```

Aber moderner gedacht ist eher:

```
Klassen = strukturierte Daten + Typen
```

Ein gutes mentales Modell
Konzept	Python Dict	Dart Class
Struktur	lose	fest
Typen	dynamisch	statisch
Fehler	runtime	compile-time
Zweck	flexibel	robust
