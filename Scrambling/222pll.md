Ja. Für PLL-artige 2x2-Fälle musst du:

* alle Corner korrekt orientieren (`orientation = 0`)
* nur die Permutation mischen
* optional den U-Layer fest lassen und nur D permutieren

Dann bekommst du reine PLL-Zustände.

Beispiel:

```js id="nq3hn3"
function randomPermutation(arr) {
  const copy = [...arr];

  for (let i = copy.length - 1; i > 0; i--) {
    const j = Math.floor(Math.random() * (i + 1));
    [copy[i], copy[j]] = [copy[j], copy[i]];
  }

  return copy;
}

/*
2x2 corners

0 UFR
1 URB
2 UBL
3 ULF
4 DFR
5 DRB
6 DBL
7 DLF
*/

// U-Layer gelöst
const solvedU = [0, 1, 2, 3];

// D-Layer zufällig permutiert
const mixedD = randomPermutation([4, 5, 6, 7]);

const state = {
  CORNERS: {
    pieces: [...solvedU, ...mixedD],

    // alle orientiert = PLL state
    orientation: Array(8).fill(0),
  },
};

console.log(state);
```

Das erzeugt Zustände wie:

* A-Perm
* U-Perm
* H-Perm
* Z-Perm ähnliche Fälle auf dem 2x2

weil:

* Orientierung komplett gelöst ist
* nur Permutation übrig bleibt

Wenn du nur echte „legale“ PLLs willst, musst du zusätzlich auf die Parität achten:

Eine gültige Corner-Permutation muss gerade sein.

Dafür kannst du einfach neu mischen bis die Permutation gerade ist.

Zum Beispiel:

```js id="n79ifw"
function isEvenPermutation(arr) {
  let inversions = 0;

  for (let i = 0; i < arr.length; i++) {
    for (let j = i + 1; j < arr.length; j++) {
      if (arr[i] > arr[j]) inversions++;
    }
  }

  return inversions % 2 === 0;
}

function randomEvenPermutation(arr) {
  let perm;

  do {
    perm = randomPermutation(arr);
  } while (!isEvenPermutation(perm));

  return perm;
}
```

Dann:

```js id="lx9zpl"
const mixedD = randomEvenPermutation([4,5,6,7]);
```

Damit bekommst du nur echte erreichbare 2x2-PLL-Zustände.

Ja — wenn du den State wirklich in `cubing.js` benutzen willst, brauchst du zusätzlich `KPuzzle` bzw. meistens direkt ein bestehendes Puzzle wie den 2x2-Cube.

Zum Beispiel:

```js id="fj3zk2"
import { puzzles } from "cubing/puzzles";
```

Dann holst du dir das 2x2-KPuzzle:

```js id="yzq8j6"
const cube2x2 = await puzzles["2x2x2"].kpuzzle();
```

Und daraus erzeugst du ein Pattern:

```js id="iwfy0x"
const pattern = cube2x2.createPattern(pllState);

console.log(pattern);
```
