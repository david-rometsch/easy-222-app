# Flutter app: Easy-222
## Aim 
This is my first Flutter-App. 
It can be used to Train difficult cases for Speedcubing in the category 
2x2. 
For now it uses static Srambles (fixed list)
It works like flash Cards using spaced repetition. 
each scramble that you find difficuld is marked and shows up more than
than others providing you with an easy training for you weaknesses trough 
repetition. You just focus on your solves and Easy-222 does the rest for 
you!

## Technology
This app shows the following Technologies:
- Multiple Screens
- API-Functionallity
- Sensor use

## Integrate new scramblelist
```sh
cd app/
make assets/scrambles.jso
```
